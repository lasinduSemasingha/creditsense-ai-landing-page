What We Built

Four Integrated Modules

Each module addresses a critical pain point in financial leasing operations — from predicting customer defaults to automating regulatory compliance.

🎯

Default Risk Prediction

XGBoost-powered classification model trained on 188,866 leasing records to predict customer probability of default with 99.98% accuracy and 100% ROC-AUC.

📊

Branch Performance Analysis

Clustering and binary classification ('Good'/'Poor') using arrears ratio, NPL status, and payment recency to surface underperforming branches proactively.

💬

RAG Conversational Assistant

Retrieval-Augmented Generation chatbot with FAISS vector search, multimodal input (STT/TTS/OCR), and domain-specific leasing knowledge base.

📈

Impairment & ECL Estimation

CatBoost regression achieving R² of 0.9886 for impairment and 0.9446 for 1-Year ECL, fully aligned with IFRS 9 accounting standards.
